In my previous classes that included me to write code and debug some things, I have struggled with the debugging part of the class and often needed some outside help to figure out exactly what was wrong. I know that some software can contain hundreds to thousands of lines of code, and being able to manage all of those lines might become a little overwhelming, but I am sure that with enough practice I can overcome this struggle of debugging and maintenance.
